# Personal Portfolio Backend

Express + MongoDB API for the personal portfolio CMS, AI Copilot, analytics, logs, and admin authentication.

## Setup

1. Copy `.env.example` to `.env`.
2. Set MongoDB, JWT, admin, and OpenRouter values.
3. Run `npm install`.
4. Run `npm run seed`.
5. Run `npm run dev`.

The OpenRouter API key must exist only in `.env`.
