# Mohammed Nagoor Meerasha Portfolio

Premium cinematic React portfolio with separate routed pages, interactive particles, a Three.js holographic N logo, Framer Motion transitions, GSAP scroll animation, project flip cards, and EmailJS contact delivery.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Routes

- `/landing`
- `/home`
- `/about`
- `/skills`
- `/experience`
- `/projects`
- `/articles`
- `/resume`
- `/contact`

## Customize

Portfolio content and external links are centralized in `src/data/portfolio.js`.

Replace `public/Nagoor_Resume.pdf` with the final resume PDF while keeping the same filename.

The EmailJS service, template, and public key are configured in `src/pages/Contact.jsx`.
