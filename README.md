# Nagoor-Portfolio

## Personal Portfolio System

This is Mohammed Nagoor Meerasha's current working personal portfolio system.

It is intentionally separate from the general portfolio builder.

## Apps

- `frontend/`: current cinematic personal portfolio UI.
- `backend/`: personal portfolio CMS, AI Copilot, analytics, media, contact inbox, SEO, and logs API.
- `admin-dashboard/`: private admin dashboard for the personal portfolio.

## Run Backend

```bash
cd Nagoor_personal_portfolio/backend
npm install
npm run dev
```

Default URL: `http://127.0.0.1:5001`

## Run Frontend

```bash
cd Nagoor_personal_portfolio/frontend
npm install
npm run dev
```

Default URL: `http://127.0.0.1:5173`

## Run Admin Dashboard

```bash
cd Nagoor_personal_portfolio/admin-dashboard
npm install
npm run dev
```

Default URL: `http://127.0.0.1:5174`

## Important

Do not redesign this app when working on the general builder. This folder is the working personal portfolio and should remain independent.
